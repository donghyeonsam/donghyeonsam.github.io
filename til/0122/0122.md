## 모듈 (Module)

: 한 파일에 묶인 변수와 함수의 모음

  특정한 기능을 하는 코드가 작성된 파이썬 파일 (.py)

모듈 예시)

- math 내장 모듈

```python
import math # 여기서 math는 pi라는 변수와 sqrt라는 함수를 가지고 있는 math.py 파일(모듈)
print(math.pi) # 3.141592653

print(math.sqrt(4)) # 2.0
```

### — from 절 사용 —

: 코드가 짧고 간결 해진다.

- 단점
    - 정의된 모듈의 위치를 알기 어려워 명시적이지 않을 수 있다
    - 사용자가 선언한 변수 또는 함수와 겹치게 되어 모듈에서 정의한 값이나 동작이 이루어 지지 않을 수 있다

사용 방법

```python
from " 모듈이름 " import " 변수 이름 " 혹은 " 함수 이름 " 혹은 " 변수 이름 " , " 함수 이름 "
```

### — ‘ as ‘ 키워드 —

: as 키워드를 사용하여 별칭(alias)을 부여

- 두 개 이상의 모듈에서 동일한 이름의 변수, 함수, 클래스 등을 가져올 때 발생하는 이름 충돌 해결
- import되는 함수나 변수명이 너무 길거나 자주 사용해야 할 경우 ‘ as ‘ 키워드로 별칭을 정의하여 쉽게 사용

사용 방법(예시)

```python
from math import sqrt
from my_math import sqrt as my_sqrt

sqrt(4)
my_sqrt(4)
```

# 제어문 (Control Statement)

: 코드의 실행 흐름을 제어하는데 사용되는 구문

 조건에 따라 코드 블록을 실행하거나 반복적으로 코드를 실행한다.

# 조건문

### — if 문 —

: 조건문의 기본 형태

 if 문에 작성된 조건을 만족할 때 내부 코드 실행

 작성되는 조건은 표현식으로 작성한다.

### — elif 문 —

: 이전의 조건을 만족하지 못하고 추가로 다른 조건이 필요할 때 사용

 여러 개의 elif 문을 사용할 수 있다.

### — else 문 —

: 모든 조건들을 만족하지 않으면 실행된다.

사용 방법 :

```python
if 조건 1:
	조건 1을 만족할 때 실행할 코드
	
elif 조건 2:
	조건 2을 만족할 때 실행할 코드
	
elif 조건 3:
	조건 3을 만족할 때 실행할 코드
	
else:
	모든 조건을 만족하지 않으면 실행할 코드
```

## 반복 제어

: for 문과 while 문은 매 반복마다 본문 내 모든 코드를 실행하지만 때때로 일부만 실행하는 것이 필요할 때가 있다. 그럴 때 사용하는 제어 코드들이다.

### — 제어 코드 break —

- 해당 키워드를 만나게 되면 남은 코드를 무시하고 반복 즉시 종료
- 반복을 끝내야 할 명확한 조건이 있을 때 사용한다.

예시)

```python
for i in range(10):
	if i == 5:
		break
	print(i) # 0 1 2 3 4
```

---

### — 제어 코드 continue —

- 해당 키워드를 만나게 되면 다음 코드는 무시하고 다음 반복을 수행

예시)

```python
for i in range(10):
	if i % 2 == 0:
		continue
	print(i) # 1 3 5 7 9
```

- 반복 제어가 아닌 코드의 틀을 유지하거나 나중에 내용을 채우기 위한 용도로 사용한다.
- 코드를 비워두면 오류가 발생하기 때문에 pass 키워드를 사용한다.
- 반복문 뿐만 아니라 함수, 조건문에도 사용 가능하다.

## zip 함수

: 짝지어진 결과(tuple)을 하나씩 꺼내 쓸 수 있는 반복 가능한 객체 자료형

사용 방법 :

```python
zip(*iterables)
```

- 전치 행렬
- 전체 값을 확인하려면 list나 tuple로 형변환 해줘야 한다.
