## 중위 표기법 (infix notation)

: 연산자를 피연산자의 가운데 표기하는 방법  ( ex_ A + B )

## 후위 표기법 (postfix notation)

: 연산자를 피연산자 뒤에 표기하는 방법 ( ex_ AB + )

### 중위 표기법의 후위 표기법 변환 방법 1

1. 수식의 각 연산자에 대해서 우선순위에 따라 괄호를 사용하여 다시 사용한다
2. 각 연산자를 그에 대응하는 오른쪽 괄호의 뒤로 이동시킨다
3. 괄호를 제거한다

### 중위 표기법의 후위 표기법 변환 방법 2 (Stack 이용)

- 토큰 : 데이터를 처리하는 기본 단위, 분야에 따라 다양한 의미로 사용한다
1. 변환
    1. 입력 받은 중위 표기법에서 토큰을 읽는다
    2. 토큰이 피연산자면 토큰을 출력한다
    3. 토큰이 연산자(괄호 포함) 일 때,
        - 이 토큰이 스택의 top에 저장되어 있는 연산자보다 우선순위가 높으면 스택에 push
        - 그렇지 않다면 스택 top의 연산자의 우선순위가 토큰의 우선순위보다 작을 때까지 스택에서 pop한 후 토큰의 연산자를 push한다 (만약, top에 연산자가 없으면 push한다)
    4. 토큰이 오른쪽 괄호 ‘ ) ‘ 이면 스택 top에 왼쪽 괄호 ‘ ( ‘ 가 올 때까지 스택에 pop연산을 수행하고 pop한 연산자를 출력한다 (왼쪽 괄호를 만나면 pop만 하고 출력하지는 않는다)
    5. 중위 표기법에 더 읽을 것이 없다면 중지, 반면 더 읽을 것이 있다면 1-a 부터 다시 반복한다
    6. 스택에 남아 있는 연산자들 모두 pop하여 출력한다
        - 스택 밖의 왼쪽 괄호는 우선순위가 가장 높으며, 스택 안의 왼쪽 괄호는 우선 순위가 가장 낮다

**→ 이후 수식이 끝나고, 스택이 비어있다면 정상 종료**

1. 변환하여 만든 후위 표기법 식을 Stack을 이용하여 계산
    1. 피연산자를 만나면 스택에 push한다
    2. 연산자를 만나면 필요한 만큼 피연산자를 스택에서 pop하여 연산하고, 연산 결과를 다시 스택에 push한다
    3. 수식이 끝나면 마지막으로 스택을 pop하여 출력한다

아래 코드 작성 예시)

```python
stack = [0] * 10
top = -1

icp = {'(' : 3, '*' : 2, '/' : 2, '+' : 1, '-' : 1}  # 스택 밖에서의 우선순위
isp = {'(' : 0, '*' : 2, '/' : 2, '+' : 1, '-' : 1}  # 스택 안에서의 우선순위

infix = '(6+5*(2-8)/2)'  # 중위식 문자열
postfix = ' '            # 후위식 문자열

# 1번 중위식 -> 후위식 변환

for token in infix:
		if token not in '(*/+-)':  # 피연산자면 후위식에 추가
				postfix += token
		elif token == ')':         # 닫는 괄호면 여는 괄호를 만날때까지
				while top > -1 and stack[top] != '(':
						top -= 1
						postfix += stack[top + 1]				
				if top != -1:
						top -= 1           # '(' 제거
		else:                      # '(*/+-' 인 경우
				if top == -1 or isp[stack[top]] < icp[token]:
						top += 1
						stack[top] = token
				elif isp[stack[top] >= icp[token]:
						while top > -1 and isp[stack[top]] >= icp[token]:
								top -= 1
								postfix += stack[top + 1]
						top += 1
						stack[top] = token
		print(postfix, stack, top)
		
while top > -1:
		top -= 1
		postfix += stack[top + 1]
print(postfix)

# 2번 변환한 후위식 연산

stack []

for token in postfix:
    if token not in '*/+-':  # 피연산자면  push
        stack.append(int(token))       # token은 문자열 -> int로 변환
    else:                    # 연산자면
        op2 = stack.pop()    # 오른쪽 피연산자
        op1 = stack.pop()    # 왼쪽 피연산자
        result = 0
        if token == '*':
            result = op1 * op2
        elif token == '/':
            result = op1 / op2
        elif token == '+':
            result = op1 + op2
        elif token == '-':
            result = op1 - op2
        stack.append(result)  #  연산결과 push

answer = stack.pop()
print(answer)
```

## 백트래킹 (Backtracking)

: 후보해를 구성해 나가다가 더 이상 해가 될 수 없다고 판단되면 돌아가서 (backtrack) 다른 후보를 찾는 방법이다

**(백트래킹은 재귀 기반의 DFS로 작성을 하는 것이 특징이다)**

- 모든 경우의 수를 탐색하는 완전 탐색을 효율적으로 구현하는 방법
- 가능성이 있는 해를 추가해가며 완전한 해인지 검사한다
- 추가한 해가 가능성이 없는 경우 다른 해를 추가할 수 있는 이전 상태로 되돌아가 계속 탐색한다
- 최적화 (optimization) 문제와 결정 (decision) 문제에 적용한다
- 적용 예시)
    - N-Queen 문제
    - 미로 찾기
    - 순열/ 조합
    - 부분집합
    - 스도쿠

**결정문제**

: 문제의 조건을 만족하는 해가 존재하는지의 여부를 ‘ yes ‘ 또는 ‘ no’ 로 답하는 문제이다

### Backtracking 과 DFS 의 관계

- **DFS는 그래프의 모든 노드에 대한 탐색 (왔던 길을 스택에 기록하며 되짚어 가는 형식), Backtracking은 완전 탐색 문제에 대한 접근 방법이다(유망한 노드를 스택에 기록 후 순간이동으로 돌아가는 형식)**
    - Backtracking은 “ 상태 공간 트리 “ 로 문제 해결 과정을 나타낼 수 있다
    - 상태 공간 트리를 DFS로 탐색하는 것과 같다
- **Pruning (가지치기)**
    - Backtracking 은 선택한 부분 후보해가 가능성이 없다면 더 이상 그 경로를 따라가지 않고 중지한다
- **경우의 수가 많은 문제의 경우**
    - 예를 들어 N! 인 경우의 수를 가진 문제는 모든 경우의 수를 탐색할 수 없다
    - Backtracking을 적용하면 일반적으로 경우의 수가 줄어든다
    - 단, **최악의 경우에는 지수함수 시간(Exponential Time)을 요하므로 처리가 불가능하다**

## Backtracking 기법

- 어떤 노드의 유망성을 점검한 후에 유망(promising)하지 않다고 결정되면, 그 노드의 부모로 되돌아가서(Backtracking) 다음 자식 노드로 이동한다
- 어떤 노드를 방문하였을 때, 그 노드를 포함한 경로가 해답이 될 수 없다면 그 노드는 유먕하지 않다고 판단 / 반대로 해답의 가능성이 있다면 유망하다고 판단한다
- 가지치기 (Pruning) : 유망하지 않은 노드가 포함되는 경로는 더 이상 고려하지 않는다
