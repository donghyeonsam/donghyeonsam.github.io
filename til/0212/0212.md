- 다른 코드 예시)

```python
def powerset(level):
    if level == N:
        print(path)
    else:
        # 왼쪽에 1넣기
        path[level] = 1
        powerset(level + 1)
        # 오른쪽에 1넣기
        path[level] = 0
        powerset(level + 1)

arr = [1, 2, 3]
N = len(arr)
path = [0] * N
powerset(0)
```

- 자리 교환으로 순열 생성

```python
def perm(lev, N):
    if lev == N:
        print(path)
    else:
        for i in range(lev, N):
            path[i], path[lev] = path[lev], path[i]
            perm(i+1, N)
            path[i], path[lev] = path[lev], path[i]

path = [0, 1, 2]
N = 3
perm(0, N)
```
