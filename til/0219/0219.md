## Tree

- 비선형 자료구조
- 원소들 간에 1:N 관계를 가지는 자료 구조
- 원소들 간에 계층관계를 가지는 계층형 자료 구조
- 상위 원소에서 하위 원소로 내려가면서 확장되는 트리(나무) 모양의 구조

### 트리의 정의

: 한 개 이상의 노드로 이루어진 유한 집합이며 다음 조건을 만족한다

- 노드 중 최상위 노드를 루트 (root) 라고 한다
- 나머지 노드들은 (n ≥ 0) 개의 부분집합 T1, ‘’’, TN 으로 분리될 수 있다

→ 트리의 일부분을 잘라내어도 여전히 트리임을 뜻하는 말이다

![스크린샷 2026-02-19 오후 10.03.14.png](%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2026-02-19_%E1%84%8B%E1%85%A9%E1%84%92%E1%85%AE_10.03.14.png)

- 노드 (node) : 트리의 원소
    - 트리 T의 노드 : A, B, C, D, E, F, G, H, I, J, K
- 간선 (edge) : 노드를 연결하는 선 (부모 노드와 자식 노드를 연결)
- 루트 노드 (root node) : 트리의 시작 노드
    - 트리 T의 루트 노드 : A

![스크린샷 2026-02-19 오후 10.04.23.png](%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2026-02-19_%E1%84%8B%E1%85%A9%E1%84%92%E1%85%AE_10.04.23.png)

- 형제 노드 (sibling node)
    - 같은 부모 노드의 자식 노드들
    - B, C, D 는 형제 노드
- 조상 노드
    - 간선을 따라 루트 노드까지 이르는 경로에 있는 모든 노드들
    - K의 조상 노드 : F, B, A,
- 서브 트리(subtree)
    - 부모 노드와 연결된 간선을 끊었을 때 생성되는 트리
- 자손 노드
    - 서브 트리에 있는 하위 레벨의 노드들
    - B의 자손 노드 : E, F, K
- 노드의 차수
    - 노드에 연결된 자식 노드의 수
    - B의 차수 = 2, C의 차수 = 1
- 트리의 차수
    - 트리에 있는 노드의 차수 중에서 가장 큰 값
    - 트리 T의 차수 = 3
- 단말 노드 (leaf node)
    - 차수가 0인 노드 (자식 노드가 없는 노드)
- 노드의 높이
    - 루트에서 노드에 이르는 간선의 수 (노드의 레벨)
    - B의 높이 = 1, F의 높이 = 2
- 트리의 높이
    - 트리에 있는 노드의 높이 중에서 가장 큰 값 (최대 레벨)
    - 트리 T의 높이 = 3

## 이진 트리

: 모든 노드들이 2개 이내의 서브 트리(자식)를 갖는 특별한 형태의 트리

- 각 노드가 자식 노드를 최대한 2개까지만 가질 수 있다
    - 왼쪽 자식 노드 (left child node)
    - 오른쪽 자식 노드 (right child node)

이진 트리의 예시)

![스크린샷 2026-02-19 오후 10.08.52.png](%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2026-02-19_%E1%84%8B%E1%85%A9%E1%84%92%E1%85%AE_10.08.52.png)

### 이진 트리의 특성

- 레벨 i에서의 노드의 최대 개수는 2^i 개
- 높이가 h인 이진 트리가 가질 수 있는 노드의 최소 개수는 (h+1)개가 되며, 최대 개수는 (2^(h+1) - 1) 개가 된다

![스크린샷 2026-02-19 오후 10.09.47.png](%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2026-02-19_%E1%84%8B%E1%85%A9%E1%84%92%E1%85%AE_10.09.47.png)

### 포화 이진 트리 (Full Binary Tree)

- 모든 레벨에 노드가 포화상태로 차 있는 이진 트리
- 높이가 h일 때, 최대 노드의 개수인 (2^(h+1) - 1) 의 노드를 가진 이진 트리
    - 높이가 3일 때 (2^(h+1) - 1) 까지 정해진 위치에 대한 노드 번호를 가진다

![스크린샷 2026-02-19 오후 10.11.06.png](%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2026-02-19_%E1%84%8B%E1%85%A9%E1%84%92%E1%85%AE_10.11.06.png)

### 완전 이진 트리 (Complete Binary Tree)

- 높이가 h이고 노드 수가 n개 일 때 (단, 2^h ≤ n ≤ 2^(h+1) - 1)
- 포화 이진 트리의 노드 번호 1번부터 n번까지 빈 자리가 없는 이진 트리
    - ex) 노드가 10개인 완전 이진 트리

![스크린샷 2026-02-19 오후 10.12.22.png](%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2026-02-19_%E1%84%8B%E1%85%A9%E1%84%92%E1%85%AE_10.12.22.png)

### 편향 이진 트리 (Skewed Binary Tree)

- 높이가 h에 대한 최소 개수와 노드를 가지면서 한쪽 방향의 자식 노드만을 가진 이진 트리
    - 왼쪽 편향 이진 트리
    - 오른쪽 평향 이진 트리

![스크린샷 2026-02-19 오후 10.13.07.png](%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2026-02-19_%E1%84%8B%E1%85%A9%E1%84%92%E1%85%AE_10.13.07.png)

### 배열을 이용한 이진 트리의 표현

- 루트의 번호를 1번으로 부여
- 레벨 n에 있는 노드에 대하여 왼쪽부터 오른쪽으로 2^n부터 2^(n+1) - 1 까지 번호를 차례로 부여
- 포화 이진 트리, 완전 이진 트리에 적합하다’

### 노드 번호의 성질

- 노드 번호가 i인 노드의 부모 노드 번호 : i // 2
- 노드 번호가 i인 노드의 왼쪽 자식 노드 번호 : 2 * i
- 노드 번호가 i인 노드의 오른쪽 자식 노드 번호 : 2 * i + 1
- 레벨 n의 노드 번호 시작 번호 : 2^n

## 순회 (Traversal)

: 트리의 노드들을 체계적으로 방문하는 것 (중복되지 않게)

(트리는 비선형 구조이기 때문에 선형 구조에서와 같이 선후 연결 관계를 알 수 없다)

##중요##

→ **“ 서브 트리 루트에서 순회를 시작하면 서브 트리 안에서만 순회한다 “**

- 전위 순회 (Preorder Traversal) : VLR
    - 부모 노드 방문 후, 자식 노드를 좌, 우 순서로 방문한다
- 중위 순회 (Inorder Traversal) : LVR
    - 왼쪽 자식 노드, 부모 노드, 오른쪽 자식 노드 순으로 방문한다
- 후위 순회 (Postorder Traversal) : LRV
    - 자식 노드를 좌, 우 순서로 방문한 후, 부모 노드로 방문한다

![스크린샷 2026-02-19 오후 10.20.05.png](%E1%84%89%E1%85%B3%E1%84%8F%E1%85%B3%E1%84%85%E1%85%B5%E1%86%AB%E1%84%89%E1%85%A3%E1%86%BA_2026-02-19_%E1%84%8B%E1%85%A9%E1%84%92%E1%85%AE_10.20.05.png)

### **전위 순회 (Preorder Traversal)**

- 수행 방법
    1. 현재 노드 n을 방문하여 처리한다 -> V
    2. 현재 노드 n의 왼쪽 서브 트리로 이동한다 -> L
    3. 현재 노드 n의 오른쪽 서브트리로 이동한다 -> R
- 전위 순회 알고리즘

→ 왼쪽 자식 노드로 진입 (없다면 리턴) → 오른쪽 자식 노드로 진입 (없다면 리턴)

### **중위 순회 (Inorder Traversal)**

- 수행 방법
    1. 현재 노드 n의 왼쪽 서브트리로 이동한다 -> L
    2. 현재 노드 n을 방문하여 처리한다 -> V
    3. 현재 노드 n의 오른쪽 서브트리로 이동한다 -> R
- 중위 순회 알고리즘

→ 왼쪽 자식 노드로 진입 (없다면 리턴) → 오른쪽 자식 노드로 진입 (없다면 리턴)

- 수행 방법

    2. 현재 노드 n을 오른쪽 서브트리로 이동한다 -> R
    3. 현재 노드 n을 방문하여 처리한다 -> V
- 후위 순회 알고리즘

→ 왼쪽 자식 노드로 진입 (없다면 리턴) → 오른쪽 자식 노드로 진입 (없다면 리턴)

### 수식 트리

: 수식을 표현하는 이진 트리 (수식 이진 트리) (Experssion Binary Tree)

### TREE 연습문제 코드

```python
# TREE 연습문제 (Traversal) (pre, in, post)

def pre_order(T):  # 전위순회
		if T:
				print(T)                #  부모 방문
				pre_order(left[T])      # 왼쪽 자식 (서브트리) 으로 이동
				pre_order(right[T])     # 오른쪽 자식으로 이동
				

def in_order(T):   # 중위순회
		if T:
		in_order(left[T])         # 왼쪽 자식 (서브트리) 으로 이동
		print(T)                  # 부모 방문
		in_order(right[T])        # 오른쪽 자식으로 이동
		
		
def post_order(T):  # 후위순회
		if T:
		post_orer(right[T])       # 오른쪽 자식으로 이동
		post_orer(left[T])        # 왼쪽 자식으로 이동
		print(T)                  # 부모 방문
```

**→ 방문 순서만 바꾸어 주면 전위, 중위, 후위로 변경 가능** 

```python
# 입력 받는 방법

V = int(input())    # 정점 수 (1~V) 번 까지의 정점
E = V - 1           # 간선 수
arr = list(map(int, input().split()))

# 부모를 인덱스로 자식 저장
left = [0] * (V + 1)
right = [0] * (V + 1)

# 자식을 인덱스로 부모 저장
par = [0] * (V + 1)

for i in range(E):
		p, c = arr[i*2], arr[i*2 + 1]
		if left[p] == 0:          # 왼쪽 자식이 없다면 왼쪽에 자식 저장
				left[p] = c
		else:                     # 왼쪽 자식이 있다면 오른쪽에 자식 저장
				right[p] = c
		par[c] = p                # 자식을 인덱스로 부모를 저장

root = 1          # 루트를 1이라고 가정하고 루트 찾기 (조상 찾기) 
for i in range(1, V+1):
		if par[i] == 0:           # 부모가 없으면 root
				root = i
				break
pre_order(root)               # 루트부터 전위순회
print()
in_order(root)                #  중위순회
print()
post_order(root)              #  후위순회		
```
